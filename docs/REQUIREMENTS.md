# Requerimientos del Sistema

## Requerimientos Funcionales

### RF01
El sistema debe permitir crear pedidos.

### RF02
El sistema debe permitir actualizar estados de pedidos.

### RF03
El sistema debe permitir gestionar productos.

### RF04
El sistema debe permitir gestionar inventario.

### RF05
El sistema debe permitir visualizar rutas de entrega.

---

## Requerimientos No Funcionales

### RNF01
El sistema debe ser responsive.

### RNF02
El sistema debe ser fácil de usar.

### RNF03
El sistema debe tener autenticación segura.

### RNF04
El sistema debe permitir múltiples usuarios.
