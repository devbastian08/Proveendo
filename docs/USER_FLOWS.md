# Flujos del Sistema

## Flujo de Pedido

1. Tendero recibe enlace por WhatsApp
2. Ingresa a la página
3. Selecciona productos
4. Confirma pedido
5. Distribuidora recibe pedido
6. Pedido pasa a preparación
7. Pedido sale a entrega
8. Pedido es entregado

---

## Flujo del Conductor

1. Conductor inicia sesión
2. Visualiza pedidos asignados
3. Realiza entregas
4. Actualiza estado

---

## Flujo del Asesor

1. Visita tienda
2. Registra pedido
3. Envía pedido a distribuidora
