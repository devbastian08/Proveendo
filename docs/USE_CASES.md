# Casos de Uso

## Caso de Uso: Crear Pedido

### Actor
Tendero

### Flujo
1. Ingresa al enlace
2. Selecciona productos
3. Confirma pedido
4. Sistema registra pedido

---

## Caso de Uso: Actualizar Pedido

### Actor
Administrador

### Flujo
1. Ingresa al panel
2. Selecciona pedido
3. Cambia estado
4. Sistema actualiza pedido

---

## Caso de Uso: Entregar Pedido

### Actor
Conductor

### Flujo
1. Visualiza pedido
2. Realiza entrega
3. Marca pedido como entregado
